# Bivalvos como Indicador Paleoambiental

## Rasgos morfológicos

| Parte Morfológica | Subtipos | Significado Paleoecológico | Paleoambiente Inferido |
|---|---|---|---|
| **Charnela y dentición** | Taxodonta, esquizodonta, heterodonta, disodonta, isodonta, edentada/adonta. | Heterodonta: infaunal excavador.<br>Taxodonta: excavador somero.<br>Disodonta: epibisado.<br>Edentada: cementante o excavador profundo. | Marino en general; heterodontos también en salobres y dulceacuícolas. |
| **Forma y contorno** | Globosa, comprimida, ensiforme, pectiniforme, cilíndrica, etc. | Traduce velocidad y profundidad de excavación.<br>Ensiforme = excavador rápido profundo.<br>Globosa = somero lento. | Ensiforme: playa e intermareal arenoso de alta energía.<br>Cilíndrica: rockground / hardground. |
| **Equivalvia / Inequivalvia** | Equivalvo, inequivalvo, valvas torsionadas. | Inequivalvo = comisura paralela u oblicua al sustrato (cementante o apoyado).<br>Valva inferior inflada ("snowshoe"). | Fondos fangosos blandos de baja energía (apoyados) o fondos duros de alta energía (cementantes). |
| **Umbo (posición y orientación)** | Prosógiro, opistógiro, ortógiro, terminal, enrollado. | Prosógiro no terminal: heterodonto típico.<br>Terminal: epibisado mytiliforme.<br>Enrollado: apoyado sobre fango. | Umbo terminal apunta a sustrato duro con biso; el enrollado indica fondo fangoso blando. |
| **Espesor de valva y talla** | Gruesa/robusta, delgada/frágil, enana. | Valva gruesa: alta energía y depredación.<br>Valva delgada: baja energía o profundidad.<br>Enanismo: estrés salino. | Gruesa: litoral cálido de alta energía.<br>Delgada: offshore o cuenca.<br>Enanismo: estuario o lagoon. |
| **Ornamentación** | Costillas radiales/concéntricas, lamelas, espinas, lisa. | Ornamentación fuerte = anclaje, estabilidad y defensa (opuesta a penetración rápida).<br>Superficie lisa = excavación rápida o natación. | Costillas y espinas: submareal somero, alta energía.<br>Lisa: infralitoral arenoso o nectobentónico.<br>Lamelas: aguas tranquilas. |
| **Líneas de crecimiento** | Anillos anuales, mareales, de disturbio (disturbance rings). | Reflejan estacionalidad, tasa de crecimiento, longevidad, temperatura y eventos de estrés (tormentas). | Permite distinguir ambientes intermareales (incrementos mareales) de submareales.<br>Anillos anuales marcados indican latitudes medias/altas. |

## Modos de vida

| Modo de vida | Categoría | Descripción |
|---|---|---|
| **1. Infaunales**<br>Viven dentro del sedimento (soft to firm) | Excavadores someros (Shallow infaunal) | Viven cerca de la superficie del sedimento con sifones cortos para la entrada y salida de agua. |
| | Excavadores profundos (Deep infaunal) | Se entierran a mayor profundidad. Poseen sifones muy largos que alcanzan la interfaz agua-sedimento para alimentarse y respirar. *Ensis* presenta forma ensiforme para rápida excavación. |
| **2. Epifaunales**<br>Viven sobre la superficie del sustrato | Cementados (Firm to hard substrate) | Fijados permanentemente a sustratos duros mediante la cementación de una de sus valvas. |
| | Fijados por biso (Epibisados) | Se anclan a fondos firmes o duros mediante filamentos de biso. |
| | Nectobentónicos / Nadadores o Apoyados | Forma pectiniforme comprimida; descansan libremente sobre el fondo y pueden desplazarse mediante propulsión a chorro. |
| | Liberosésiles / Apoyados (Soft to firm substrate) | Inequivalvos con la valva inferior inflada ("efecto raqueta/snowshoe") para descansar sobre fondos fangosos o blandos sin hundirse. |
